# Provenance

The two JSON-LD context documents in this directory are bundled into the crate with `include_str!`, so that the NGSI-LD core context, which clause 4.4 makes implicitly present in every `@context`, is processed without any network access. They are copied unchanged.

`ngsi-ld-core-context-v1.9.jsonld` is the NGSI-LD core context v1.9 that ETSI publishes at https://uri.etsi.org/ngsi-ld/v1/ngsi-ld-core-context-v1.9.jsonld (SHA-256 `9e8633554f8607c07d59b88b90d2d0198cb3eb7c37626391be41c5d44fe98ced`, 14853 bytes). The ETSI server refused the download when it was bundled (HTTP 403 on 2026-10-20), so the file was taken from the copy of release v1.9 a sibling NGSI-LD project embeds, in its published formatting. It has not been compared with the document the ETSI server serves byte for byte. It is distributed under the BSD-3-Clause licence in `LICENSE-ETSI`, which applies to this file only.

`data-integrity-v2.jsonld` is the W3C Data Integrity v2 context, https://w3id.org/security/data-integrity/v2, which redirects to https://www.w3.org/2025/credentials/vcdi/context/v2.jsonld (`Content-Type: application/ld+json`, `Last-Modified: Tue, 11 Mar 2025 15:32:06 GMT`, SHA-256 `67f21e6e33a6c14e5ccfd2fc7865f7474fb71a04af7e94136cb399dfac8ae8f4`), downloaded on 2026-10-20. The core context's `ngsildproof` term imports it as part of its scoped context, and JSON-LD context processing validates scoped contexts, so the core context cannot be processed without it.
